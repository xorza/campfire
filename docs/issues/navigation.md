# Navigation

Design: [Navigation](../design/04-capabilities/navigation.md). Rules: [Issue log](../../AGENTS.md#issue-log).

## Decide

- A dash or a knock back ends only before a static body ([Forced movement](../design/04-capabilities/navigation.md#forced-movement)): it passes through the map's walls and may end inside one, where no walker may stand. The options: a forced move ends before the first step whose way touches a cell the walls block, as it ends before a static body; or it passes over walls and, where it ends in a blocked cell, goes to the nearest open one, as a teleport does and as League of Legends' dashes over walls do.
