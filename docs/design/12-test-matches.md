# Test matches

A proposal for one slice. When it ends, each lasting decision moves into the document of the system it governs, and this document is deleted ([A slice's proposal is temporary](../../AGENTS.md#documents)); its plan is in `PLAN.md`. Its facts are in [Test matches](../research/test-matches.md).

**At the slice's end** the user starts the client as a spectator of Tournament Desert, where two bots, China and America, each start with a base of every building its faction builds and two of each unit it trains, and send their armies at each other; and the user starts a match of their own on such a base, with `--pick 0:start=base`.

## Decisions

### Sessions

- **A local session may seat bots alone.** On the local server, a plan of no player seat opens, its match starts as its watcher joins, so the watcher sees it from its first tick, and it ends as its match ends or its client closes it, as no player is left to leave, as OpenRA's skirmish server starts a game of bots while its host spectates and shuts down as its host leaves. The dedicated server still refuses a plan of no player, as OpenRA's dedicated server needs human players unless its host sets `EnableSingleplayer`. Refused: a match that starts as its lobby opens, before the watcher's link joins, which shows a match already under way; a seat of a player who never plays, held for the watcher, which the log would record as a player and which takes a start a two-player map lacks; a dedicated server's watch, which no test needs yet.
- **A local watcher takes no seat and sees every unit.** With `--spectate`, the local client holds no seat, so a server bot may hold seat 0, and the local server admits its one spectator, who sees every unit through any fog, as a test watches both bases, so the client refuses `--watch` there. Refused: all teams' views, as a Dota 2 spectator picks, which hides what neither team sees; a dedicated server beside the client, where singleplayer is a local server ([Sessions](08-sessions.md), Singleplayer is a local server).

### Spawns

- **Every body is tested for room.** `spawn_unit` refuses a unit whose body overlaps a wall, a static body, or any body the same call spawns, a circle as a box, a walker's among them. Refused: the test of boxes alone, under which a cylinder building spawns over another and a call's walkers spawn on one point.
- **A script finds room near a point.** `room_near(type, position, gap, steps)` gives the nearest point within `steps` gaps of `position`, at most 128, on a grid of `gap` meters round it, by distance and then by angle from `+x` as a facing turns, each compared exactly, where a unit of `type` has room as `spawn_unit` tests it, `gap` meters clear of each body and wall; none when no point within its steps has room, as StarCraft II's search takes its range. Its range counts grid steps, as a script call takes one number of meters at most, and so its bound is exact. It takes the nearest point, as StarCraft II's `UnitTypePlacementFromPoint` and Age of Empires II's `find_closest` do, so a base stands packed round its start and the same in every match. Refused: a cell drawn at random from an annulus, as OpenRA's support actors take, under which a test does not repeat; positions in data for each map and faction, made again for each.
- **A building that spawns whole frees its units.** A producer that spawns whole, not as a site, sends its free units and its kept spawns as it spawns, on the server, never as a restore or a client brings it back, as Zero Hour's `SpawnBehavior` acts as its object is made, whatever made it, and StarCraft II's `UnitCreate` makes a unit whole unless asked to construct it. Refused: free units of a site alone, under which a base start's supply center frees no gatherer.

### Zero Hour

- **A seat picks its start.** The rules package's choice `start` gives each seat `standard` or `base`, for a player and a bot alike, as OpenRA's lobby option `startingunits` gives each player a class of start. Refused: a saved match, which fixes both players and loads on one release alone ([Sessions](08-sessions.md), Saves run on one release); a host option for the whole match, under which a base cannot fight a plain start; cheats of fast build and cash, as OpenRA's debug menu gives, under which every test starts by building and a bot gains nothing.
- **A base start.** A seat of `base` starts with its faction building, then every other building its start builder builds, once each, in its command set's order, as Age of Empires II's Empire Wars starts each player with its buildings and workers placed, each at the room nearest its start within 40 steps of a gap of 10 m, the original's pathfind cell, so a walker passes between two, and `base_count` units, 2, of each type those buildings and its faction building train, each at the room nearest its rally within 20 steps of the same gap, as the package measures in the original's units, where a dozer's radius is 18 and a command center 120 by 140; its start units take the same room. A building or a unit with no room within its range is left out. The import writes each faction's `base_buildings_<faction>` and `base_units_<faction>` from the command sets it converts. Refused: a hand-written list of each faction's base, twelve to keep as the import converts more, which the import already holds.
- **Bots that fight from a base.** The check's bots gain a script for each of Tournament Desert's two starts that trains its units, sends its army into the other start every 40 s, and orders it to attack the nearest enemy it sees 20 s after each move, as a move passes enemies by and Zero Hour's scan passes over structures; so a match ends when one side's last building that counts falls. Refused: moves alone, under which the armies pass each other and no base falls.
