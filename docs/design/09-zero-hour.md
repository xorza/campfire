# Campfire — Zero Hour

Command & Conquer: Generals – Zero Hour, imported from the player's own copy and played on Campfire's sim, so close to the original that no player notices a difference. The facts the import takes from are [Zero Hour research](../research/zero-hour.md).

## Decisions

- **Zero Hour is the first import.** EA released the source of Generals and Zero Hour under GPL v3 in February 2025, so every rule has a written specification, and most of the game is INI data of modules from a fixed library; Zero Hour, not the base game, as the community plays it.
- **Written from the released source, under MIT/Apache-2.0.** The importer and the rules package read the original's formulas, the order of their operations and its pathfinder closely, but the code is our own; a release that ships it takes a legal check first, and no file of the original or line copied from it enters the repository.
- **Generic modules are capabilities, Zero Hour's own are Rhai.** A module another game shares becomes a capability or an option of one; one only Zero Hour has, a general's power, its veterancy, is Rhai in the rules package; the pathfinder and the locomotors, which Rhai cannot match and a player feels in every move, become navigation backends, so the core keeps no Zero Hour word.
- **One reproducible package.** The same install, game version and importer release give the same bytes on every OS, assets included, so a session names the package by fingerprint; nobody distributes it, and each player, server and verifier makes their own.
- **Parity is read from the source, and no test plays the original.** The tests pin what the port read against cases worked by hand.
- **A name too long is refused, not cut.** A name of the original goes lowercase, each byte a declared name lacks `_`; one past `DeclaredName::MAX_LEN` bytes, the object's own or an action's of it, is refused with the error or the drop of the stage that names it. Refused: a cut or a hash of it, which can give two objects one name the import would then refuse as a clash only by chance.
- **The presentation is data.** The client gains generic presentation systems that read data, and the importer maps Zero Hour's draw modules, effects and command sets onto them.
- **Fixtures in the tests, the install on request.** No copy of the game enters the repository or CI; the tests read small hand-written files in the original's formats, and a check on request imports the install `GENERALSZH_DATA` names, fails with none, and pins the package fingerprints a run on Linux and a run on macOS gave.
- **The check's measures are a golden file.** What the check measures and no closed form gives, as the fingerprints, the map's counts and the plays' ticks, is `checks/zero-hour-check/golden.toml`, which `CAMPFIRE_BLESS=1 cargo drive run zero-hour` writes again, as the tests' golden records are; what the game's data gives by a closed form, as a train's ticks and the money left, stays in the check's code. The check reads the walls, the start points and the resources from the match it plays. Refused: measured values as constants in the code, which a change of the importer moves by hand, one at a time.
- **A random outcome is Campfire's.** The sim draws from its own PRF, so a random outcome is not the original's.
- **The skirmish AI is a server bot.** It reads what its team's clients see and sends signed orders, where the original's AI reads its logic's state, so the port can play differently.
- **A player slot picks its start.** The import's choice `start` gives each player slot `standard` or `base`, for a player and a bot alike, as OpenRA's lobby option `startingunits` gives each player a class of start ([Test matches](../research/test-matches.md)). Refused: a saved match, which fixes both players and loads on one release alone ([Sessions](08-sessions.md), Saves run on one release); a host option for the whole match, under which a base cannot fight a plain start; cheats of fast build and cash, as OpenRA's debug menu gives, under which every test starts by building and a bot gains nothing.
- **A base start.** A player slot of `base` starts with its faction building, then every other building its start builders build, once each, in their command sets' order, as Age of Empires II's Empire Wars starts each player with its buildings and workers placed, each at the room nearest its start within 40 steps of a gap of 10 m, the original's pathfind cell, so a walker passes between two, and `base_count` units, 2, of each type those buildings and its faction building train, each at the room nearest its rally within 40 steps of the same gap, after the buildings, as the package measures in the original's units, where a dozer's radius is 18 and a command center 120 by 140; its start units take the same room within 20 steps. A building or a unit with no room is left out, and the import's script limits hold a start of eight bases. The import writes each faction's `base_buildings_<faction>` and `base_units_<faction>` from the command sets it converts. Refused: a hand-written list of each faction's base, twelve to keep as the import converts more, which the import already holds.
- **A builder and an attacker.** The Zero Hour rules package ships one bot script, which its mode data names twice: `builder`, which builds each building of its faction's base list that it lacks and does nothing once its base is whole, so on a base start it idles until a building falls and then builds it again; and `attacker`, which does what the builder does, trains its army from its producers, and sends the army once it is as large as its param `army`, or once no more of it comes, as OpenRA's squad manager attacks with `SquadSize`: its idle units attack-move at the nearest hostile the first of them sees within `sight`, or at the nearest enemy start, and those within `reach` of it attack it by an order; while it gathers, its idle units at home go so at an enemy it sees within its param `guard` of its start, as OpenRA's `ProtectOwn` sends idle units at an attacker, while those beyond `guard`, out with the army, attack on whatever its count, as OpenRA's attack squad goes on as it loses units and flees only when it cannot win (`GroundStates.cs`) ([Test matches](../research/test-matches.md)). Either plays from a standard start or a base start, and gathers. The slice's bots play China and GLA, whose gatherers walk; a bot of America earns nothing until aircraft come (The USA's income waits for aircraft). Refused: a file for each faction and start, as an order script must be; behaviours by a timeline, whose waves the defenses wear down as fast as they come ([Test matches](../research/test-matches.md)); a random bonus to the army's size, as OpenRA draws one for each squad, which a seeded draw would need to repeat; no defense, under which an enemy at the base's edge meets no army.
- **The bots' limits are measured.** The imported mode's call limit, and each pool's limit for a tick, is twice the most operations one think of the check's bots runs, rounded up, 40,000 of 17,843 on 23 October 2026, as a longer match's bases grow; the check pins that most, so a script that costs more fails it before a match does. The engine's call cannot pause and resume in a later tick, as OpenTTD's scripts do ([OpenTTD wiki](https://wiki.openttd.org/en/Development/Script/Need%20To%20Know)), so a think past the limit gives no orders. Refused: the earlier 8,000, under which a base start's thinks fail; a script that does one stage a think, whose bot reacts a quarter as often.
- **The base list is the base start's.** The builder's list is the faction's `base_buildings_<faction>`, which the import writes for the base start, so the base a builder completes and the base a player slot starts with are one (A base start). Refused: a build list of the bot's own, as Zero Hour's `AIData.ini` gives one, a second list to keep beside the import's.
- **A bots' match that ends.** The Zero Hour check plays an attacker against a builder from standard starts, which ends as the builder's last building falls, and two attackers from base starts, and pins how each stands at its end or its limit; the builder of the skirmish play stays an order script of the check, a fixture. Two attackers stand once their near nodes empty, as neither strikes the other's income ([Test matches](../research/test-matches.md)). Refused: a time limit that names a winner, a rule the original does not have.
- **Bots that end a match of equals, planned.** An attacker strikes its enemy's gatherers and drop-offs first, and its gatherers go past an empty node to one that holds money, as Zero Hour's AI builds a supply center by the next supply source (`AIPlayer::buildBySupplies`) and OpenRA's rush squads strike the enemy's construction yards, so a side that loses its income falls ([Test matches](../research/test-matches.md)).
- **A bot that builds and does not fight.** The Zero Hour check's skirmish play gives its bot an order script, a fixture of the check: its dozers build a base and its buildings train infantry and vehicles, with no attack and no move toward another player; the check pins what it built and how far its units stood from its center, so the script keeps working.
- **A unit of Zero Hour is a meter.** Every distance keeps the original's number, so no scale rounds a value; the widest body therefore rises to 2,048 m, past Zero Hour's widest object of 1,196 units and its bridges of 1,117.
- **A rules package beside the imported mode.** The import writes `zero-hour/`, the rules package as the importer ships it, byte for byte, and `game/`, the mode that depends on it by a relative path, so the imported package names no path of the machine that made it.
- **The multiplayer rule for client objects.** Optimized trees, props and fluff, which the original spawns on the client alone and by a machine's detail settings, are client objects in every session, so the sim never holds them.
- **Night and snow draw their own models.** A look whose night or snow states draw other models gets variants, and the client draws a map's best match by the original's matching rule (`SparseMatchFinder::findBestInfoSlow`), a general feature any game may name its conditions for.
- **Thirty frames a second, the original's times.** The importer turns each time into frames by the original's rule and writes the milliseconds Campfire's rule turns into the same count, so no time moves by a frame.

## The importer

- **Files resolve as the original resolves them.** Every archive under the install in case-insensitive order of path, the first that holds a path keeping it, base Generals last.
- **Axes stay right-handed.** The original's `x` east, `y` north and `z` up are the engine's `x`, `−z` and `y`; an `f32` becomes the `Num` of its exact value.
- **Names become declared names,** and two that collide fail the import.
- **Textures stay as the game holds them.** A DDS keeps its DXT blocks and levels in KTX2; a TGA's levels are computed in integers in linear light, so every OS gives the same bytes.
- **Models become glTF.** Pivots become nodes and `z` up becomes `y` up as a rotation, so triangles keep their front; the import writes the GLB itself, so no encoder's version changes its bytes.
- **A W3D material becomes the one material.** A material is rough and of no specular, as no shader of the install turns specular on, or unlit where its gradient is off; a second pass or a detail stage becomes a layer with a blend and a depth bias in the material's extras, as glTF cannot say them ([Material extras in a glTF extension](02-engine-core.md#client)). What the material cannot hold, a separate ambient color and the lighting per vertex, is lost ([research](../research/zero-hour.md#models)).
- **A hue mask's alpha is no transparency.** A material of a `ZHCA` texture takes the alpha mode of its opacity alone, as the game's recolor makes the texture opaque, so every Bevy pass draws it as the main pass does. Refused: a prepass shader of its own, which repeats one rule in each pass.
- **A missing texture draws as the game's `MissingTexture`,** as a player of the original sees it.
- **Terrain as the game's renderer draws it.** Each cell's tile is its ground quad and its blends overlays, cliffs stretched when `AdjustCliffTextures` says so, written to the generic terrain file ([Client](02-engine-core.md#client)).
- **The ground the sim reads is the logic's.** Each map's `[ground]` splits every cell on the logic's diagonal and gives the partition's 40-unit cells over the playable area ([Space and map](04-capabilities/00-overview.md#space-and-map)).
- **Cliffs are walls.** The import grows the cliff cells by one ring, as the original's pathfinder grows them, and merges them row by row into rectangle walls on cells of 10, the original's pathfind cell, so no new map format is needed.
- **Only walkers and standing structures have bodies,** as the original's pathfinder routes only round a structure that is not mobile, not small and stands on the ground (`Pathfinder::classifyObjectFootprint`); a walker's circle is at most 25 m, the original's widest footprint.
- **Units move by the generic backends with the original's numbers,** its locomotor's speed and turn rate, until the `navigation::zero_hour` backends come.
- **A skirmish starts with the faction's start objects,** each player's own, at the starts of a map the original lists for skirmish, as `WaypointMap::update` counts them.
- **Each player picks a faction.** The skirmish's choice `faction` lists its values, as Zero Hour's lobby gives each slot a `PlayerTemplate` and OpenRA's lobby each player a `Faction` ([Control](04-capabilities/control.md#choices)); the import offers every template of `PlayableSide = Yes`, the 3 factions and their 9 generals, and Random, and the rules script spawns each player's own start. Refused: a host option for the whole match, which makes every match a mirror; a pick phase in the match, which the original does not have; a China start the check alone spawns, which no player plays.
- **No pick is Random.** A player slot that picks nothing, a bot's included, draws one of the 12 by the match's seeded random, as the original's new slot starts at Random (`PLAYERTEMPLATE_RANDOM`), and the check and the bot's plan name their factions. Refused: America by default, which the original does not have; a refused start, which every command line would have to avoid.
- **Every command set's trains and builds are imported,** each with the original's cost, time, queue, exit and requirements, and its name from the install's string table.
- **A cylinder structure builds as a circle.** A structure of a cylinder geometry that is not small builds on a circle of its `GeometryMajorRadius`, as it already stands on one; a small structure, as the demo trap, has no body and stays dropped.
- **A prerequisite line converts to a list.** A line of several objects becomes one entry that any of them holds; a line of a science stays dropped, as no science is imported.
- **`BuildVariations` converts to a train's variants.** A train of a type of `BuildVariations` makes its variations, each a unit type of its own object, with its own look.
- **A box is money.** A dock's node holds `StartingBoxes` × `ValuePerSupplyBox`, 75 in the shipped `GameData.ini`, and a gatherer's `take` and `unit` are `MaxBoxes` and one box of it, so a delivery pays what the original's does ([Zero Hour supply](../research/zero-hour-supply.md)). Refused: boxes as a resource of their own, which the center would have to convert.
- **A gatherer docks as a dozer builds.** A gather reaches 10 m from a dock's box, the pathfinder's cell, as a build does, and aims at every unit, as the docks stand on the neutral team; the node book picks the docks.
- **A free unit needs an exit.** A building's one-shot spawns that walk are its `free` units, as its production section holds its exit; the spawns of a building of no production are a loss.
- **A spawner takes its production update.** A building that spawns and trains nothing takes the production section of its `ProductionUpdate`, as the Stinger site and the tunnel network have one, so its spawns leave by its exit; one of none, as the Chemical general's Stinger site, drops them by `NoExit`. Refused: no section for a building that trains nothing, which dropped the tunnel's defenders, as the original gives it the production update it trains nothing with.
- **A kept `SpawnBehavior` converts to spawns.** One of no `OneShot` becomes the producer's `spawns` of its first `SpawnTemplateName`, `SpawnNumber` and `SpawnReplaceDelay`; a `OneShot` stays a free unit.
- **A hack is a channel with no end.** A `HackInternetAIUpdate` converts to a `hack` cast in its unit's last command slot: its `UnpackTime` the windup, spread by `PackUnpackVariationFactor`, its `CashUpdateDelay` the channel's tick, its `PackTime` the wind-down, and its regular cash the pay, 1 where it is 0, as `HackInternetState::update` falls through its levels (04-capabilities/actions.md, A channel with no end). The losses list what the engine does not hold yet: the cash past regular and `XpPerCashUpdate`, as the import gives no veterancy; `CashUpdateDelayFast`, as no unit enters a building; and the pack's spread. Refused: a mode script that pays the hack, which the next game with an income of a unit would write again.
- **The USA's income waits for aircraft.** The Chinook, the USA's only gatherer, flies, and the import trains no unit that does not walk, so the USA's supply center gathers nothing until a slice brings aircraft; the losses list it. The supply drop zone's crates come by a cargo plane too, its `OCLUpdate`'s, so the import drops what an `OCLUpdate` creates, a loss of its own cause.
- **The import writes Zero Hour's money as an option.** `start_money` takes the values of `Multiplayer.ini`'s `MultiplayerStartingMoneyChoice`s in their order, its default the one marked `Default`, 10,000, as the original's lobby offers them; choices of no single default, of a value twice or past an option's 256 fail the import.
- **Eight teams of one.** A skirmish is every player alone against every other, up to eight; a start is placed only for a player slot a player or a bot holds, as the original places none for an empty player slot.
- **Life is the original's.** An object of an active or structure body has life of its maximum and start; a site starts at 1 life, as the original's does.
- **A weapon converts when it hits one target at once.** A weapon of the starting set becomes an attack with its damage, kind, range, period and clip; one the engine cannot hold is dropped and reported by cause.
- **The import converts shells, splash, scatter, pitch, turrets and slow weapons.** A weapon whose `ProjectileObject` has a `DumbProjectileBehavior` fires that object as a projectile type of the weapon's `WeaponSpeed`, twice its `GeometryMajorRadius` wide, on the behavior's curve, `hits` a filter for each of `STRUCTURES`, `CONTROLLED_STRUCTURES`, `WALLS`, `ALLIES` and `ENEMIES` its `ProjectileCollidesWith` names, each player being a team; the type takes the object's name when every weapon fires it alike, and else `<object>_<weapon>` for each, with the object's look. Its `PrimaryDamageRadius` and `RadiusDamageAffects` become its splash, its scatters its scatter, the tag `infantry`'s for `ScatterRadiusVsInfantry`, its pitches past a turn either way its pitch bound, a `WeaponSpeed` below the default of no shell and no laser its speed, and an AI module's first `Turret` its type's turret, of the original's 0.035 radians; a turret of no slot or no turn rate is none, and a weapon still drops by each cause the engine cannot hold: a projectile that flies neither as a shell nor as a missile, a radius or scatter of no projectile, a radius that spares the airborne, or a shell that detonates on what is no unit.
- **A missile converts to a steered projectile.** A weapon whose `ProjectileObject` has a `MissileAIUpdate` and a `THRUST` locomotor fires a projectile type of its locomotor's `Speed`, or its weapon's `WeaponSpeed` with `UseWeaponSpeed`, `Acceleration` and `TurnRate`, its missile's `InitialVelocity`, `DistanceToTravelBeforeTurning`, `DistanceToTargetForLock`, 75 when absent, `FuelLifetime`, and `PreferredHeight` with `DistanceToTargetBeforeDiving`; its `hits` come from `ProjectileCollidesWith`, and its type's name and look from its object, as a shell's do ([Zero Hour missiles](../research/zero-hour-missiles.md)).
- **A missile of no target flies to its point.** One of `TryToFollowTarget = No`, as the Scud's and the Strategy Center's, aims at the point where its target stood as it fired; every missile's `point_lock` is half its lock, as Zero Hour halves it for a point.
- **A secondary radius and a minimum range convert.** `SecondaryDamage` within `SecondaryDamageRadius` becomes the splash's `outer`, and `MinimumAttackRange` the attack's `min_range`.
- **Missiles the steer cannot hold stay dropped.** A stream, a weapon of a `ProjectileStreamName`, as the toxin and the flame; a sprayer, as the toxin truck's; a weapon of a `ProjectileDetonationOCL`, as the Scud's poison fields and the Super Weapon general's Patriot pulse; a missile of an `IgnitionDelay`, of `DetonateOnNoFuel`, of a garrison kill, or of no fuel, as the Scud Storm's; each by its own cause, so the check counts what remains.
- **A missile draws as a shell does.** Its object's look at its point, turned along its last step; its exhaust and its contrail are lost, as the client draws no particles.
- **Defeat by the last building that counts.** A player is defeated when its last object of `STRUCTURE` and `MP_COUNT_FOR_VICTORY` dies, and its other units are killed, as `Player::killPlayer` does; the last team standing wins. The rules data gives it as `[victory]` of the tag `counts_for_victory`, `defeat = "kill_all"` ([Victory by the last unit of a tag](04-capabilities/games.md#imported-games)).
- **Players regard the neutral team as neutral.** Each player's team regards `neutral`, the team of every object the map places, as `Neutral`, as `PlayerList::newGame` makes every player regard the neutral player, so a scan's `hostiles` passes over a civilian building and a supply dock, an order's `enemies` still takes them, and a projectile's `hostiles` for `ENEMIES` and a splash's `neutrals` for `NEUTRALS` mean what the original's mean. Refused: the neutral team as hostile, under which every idle unit would attack the map's placed objects.
- **A scan follows `AutoAcquireEnemiesWhenIdle`.** A type of an imported weapon whose AI module's field holds `Yes` scans each `MoodAttackCheckRate`, 2 s when absent, as the import converts a time; one of `No`, of no field, or of no weapon, as a dozer, does not ([Zero Hour automatic attack](../research/zero-hour-auto-attack.md)).
- **Every player's units take the human player's rule.** A scan takes only what a weapon reaches and its team sees, as `getNextMoodTarget` keeps for a human player, as a skirmish AI is a server bot that orders as a player does; a computer player's pursuit within its vision is the bot's to order. Refused: a rule by the kind of player, which the engine does not know.
- **Which targets, by the original's filters.** The rules data's `[defaults.acquire]` names the hostile units that are no structure and the hostile base defenses, the tag of `FS_BASE_DEFENSE`, as `PartitionFilterRejectBuildings` keeps for a human player; a type of `ATTACK_BUILDINGS` names every hostile unit. Refused: the filters in the importer's code, as the fixed rules are the rules package's data.
- **Continuous fire converts.** A weapon whose `WeaponBonus` gives `CONTINUOUS_FIRE_MEAN` or `CONTINUOUS_FIRE_FAST` a `RATE_OF_FIRE` gets `rate_bonus = "rate_of_fire"` and a streak of its `ContinuousFireCoast` and two stages, above `ContinuousFireOne` and above `ContinuousFireTwo` shots, each of a modifier the import writes into the mode, which adds the bonus less 1 to `rate_of_fire`, as `WeaponBonus::appendBonuses` adds it; the rules package declares the stat. A stage of no such bonus adds 0, as the original's bonus starts at 100 %; a weapon of stages and no such bonus converts with no streak, as its stages change nothing; one whose stages change another field, or coast for no time, which the engine does not hold, is dropped ([Zero Hour continuous fire](../research/zero-hour-continuous-fire.md)).
- **A clip of one shot is a period.** A weapon of `ClipSize = 1` converts to a period of its `ClipReloadTime` and no clip, as each shot of the original empties the clip and reloads it from the shot, so its `DelayBetweenShots` never counts (`Weapon::privateFireWeapon`); the engine counts a period and a reload alike from the attack's start, so the conversion is exact.
- **`NOT_SIMILAR` of a projectile's blast converts to nothing.** A projectile detonates as its own source, so `NOT_SIMILAR` spares only the allied projectiles of its type (`MissileAIUpdate::detonate`, `dealDamageInternal`), and the engine's projectiles take no damage, so the import drops the flag and changes nothing. Refused: a splash option that spares the source's kin, which no imported weapon needs. `NOT_SIMILAR` of a weapon of no projectile, and `NOT_AIRBORNE`, keep the drop.
- **Only a weapon of a rate bonus reads the stat.** Each unit holds one `rate_of_fire`, where Zero Hour gives each weapon its own bonus of the object's stage; no imported unit with a streak weapon has another weapon that reads the stat. Refused: the stat on every weapon, which would speed a unit's other weapons with its streak.
- **Zero Hour's units come before its structures.** The import writes the picking tiers `all:!structure` and a least radius of 10 pixels, as StarCraft II and Spring prefer units, where the original picks by its nearest triangle alone ([The mode chooses its picking](02-engine-core.md#client)). Refused: the original's pick, which a wall of a building takes from the unit before it.

## The rules package

- **No file of the game.** `source/packages/zero-hour/` holds the Rhai of the modules only Zero Hour has, the modes' setup and end, and its presentation scripts, which are planned; it ships with the importer.
- **The fixed rules are its data.** What every install holds the same, the money resource, the stats and life pool, the damage types, the tags, the start markers' tag and the slot kinds, is the rules package's `data/rules.toml`, which the imported mode's data lies over, and so is what every type shares, a death that despawns and a turret's aim tolerance and slot kind, as its `[defaults]` under each type's own (03-game-scripting.md, Defaults under each unit type); the import writes only what the install gives: the armors, weapons, trains, builds, start objects, money choices and each type's own fields. Refused: the fixed rules as Rust templates in the importer, which repeated each name the rules script reads, as OpenRA ships a mod's rules as its YAML.

## Losses

What the import does not hold against the original:

- **Driving.** A unit reaches its speed and stops at once, and turns in place before it drives, where the original accelerates, brakes and turns while it drives.
- **Paths.** A walker may stand where its center lies its radius from every wall, where the original needs whole cells clear; a fence blocks nothing, where the original routes round its line.
- **The start.** The command center stands unturned, and a starting unit where collision leaves it.
- **The widest walkers** collide as circles of 25 m.
- **Range.** Measured from each body's edge, a box's from its box, where the original measures from bounding circles, which hold a box's corners.
- **Weapon choice.** A unit attacks with its first weapon whose targeting selects the target, where the original picks the best for each target.
- **Dropped weapons.** Weapons that fire a stream, a sprayer, or a missile that ignites late, bursts as its fuel ends, kills a garrison or never runs out of fuel, that leave objects where they detonate, splash or scatter with no projectile, spare the airborne, detonate on shrubbery or projectiles, or need a minimum range past their range or a random delay are not imported until the engine holds them.
- **A missile's flight.** A missile starts at its attacker's center, as a shell does, toward its target and not along its launcher's facing; as its fuel runs out it ends where it stands, its splash bursting there, where the original's falls; and a missile whose target dies ends where it stands, its splash bursting there, where the original's destroys itself with no detonation.
- **A shell's flight.** A shell starts at its attacker's center, not its barrel's bone (`Weapon::positionProjectileForLaunch`), so its curve may take a point more; its points are exact where the original's forward differences in `f32` gather rounding, so a contact at a body's very edge may fall a tick apart; of two bodies a shell meets in a tick it hits the lower stable id, where the original takes its contact list's order.
- **A shell's reach.** A splash measures to a body's volume, the original to its bounding sphere, which holds a box's corners; a sphere's volume rises from its ground point, where the original's stands around its position; and every pitch is measured, where the original holds a target within 10 units of height in reach whatever its pitch.
- **The ground's height.** It is computed from the samples and rounded once, where the original rounds its fractions of a cell in `f32` first, and a point past the grid takes the nearest point's height, where the original takes one clamped sample (`getClipHeight`), in a ring outside the playable area.
- **A projectile's life and its effects.** A shell or a missile has no life, so nothing shoots one down, and no muzzle flash, exhaust, contrail, explosion, recoil or sound shows it; no weapon bonus or upgrade changes one.
- **A turret that does not turn.** A turret of no `TurretTurnRate`, the combat bike's, gives no turret, so its weapon fires at any bearing, where the original holds it to the body's facing.
- **Retaliation.** An idle unit does not answer an attacker beyond its weapons' reach, where the original sends idle allies after it.
- **A turret on the move.** A unit's turret scans only while its unit stands idle, where the original's turret takes targets while its unit drives.
- **Line of sight.** A scan takes a target its team sees, through what blocks sight, where the original's `ATTACK_NEEDS_LINE_OF_SIGHT` needs a clear line.
- **A melee chase.** A scanned target is dropped out of reach for every weapon, where the original's contact weapons chase it.
- **Stealth.** `Stealthed` is not read, as no unit hides.
- **Base defenses.** The Patriot, the Fire Base, the Gattling Cannon, the tunnel network and the Stinger site fire; the demo trap, a small structure of no body, is not built.
- **Spawns.** The Stinger site's soldiers leave by the free cell nearest its center, where the original stands them on its roof by its bones, and its damage does not pass to them while they live (`HiveStructureBody`); the tunnel network holds no units.
- **Build variations.** A unit's variation is drawn as a train makes it, from the match's random, so it is not the original's; a map's placed object of variations stays its own type.
- **Weapon sets and bonuses.** Only the set of `Conditions = None`; no upgrade or veterancy changes a weapon.
- **Other bodies.** Objects of an immortal, highlander, undead, hive or inactive body have no life.
- **Deaths.** A unit that dies goes at once: no death animation, rubble or death object.
- **Alliances.** Each player is its own team.
- **Power.** A building's power is not imported, so a player short of power builds at full speed.
- **The ground under a building** is not flattened as the original flattens it.
- **A site's look.** A site draws its building whole, not its scaffold.
- **The panel.** Text buttons, with no images, hotkeys, sell, upgrades or powers.
