# Test matches

How the engine seats a watcher and starts a player today, and how other games start a match of bots with an observer or a player with more than its usual start, read on 21 October 2026: the engine from its code at `3feac7a58`; the others from their sources as linked.

## The engine today

- **A session needs a player.** `Lobby::new` refuses a plan of no player seat with `LobbyError::NoPlayer` (`net/src/sim_server/lobby/mod.rs`), and a started session ends once every player left (`SimServerWorld::exit_due`), which a session of no player would meet at once.
- **The local server seats its client in seat 0.** `LocalServer::start` marks every seat but 0 and the bots' open, and opens the session with `HostVisibility::default()`, which admits no spectator (`net/src/local/local_server/mod.rs`); the client's command line refuses a server bot in seat 0 (`ServerBotError::ClientSlot`). So `--local --spectate` joins nothing: the match waits for seat 0's player.
- **The dedicated server seats a player in each seat no bot holds.** `campfire-server` opens the mode's 8 seats, and a session of two bots on Tournament Desert waits for six players.
- **A watcher exists.** A client of `JoinRole::Watch` joins as a spectator (`net/src/sim_server/offering.rs`), and `--watch <team>` picks a team's view.
- **Zero Hour's start is a script.** The rules package's `on_match_start` spawns each seated player's faction building at `Player_<n>_Start` and its start units at `Player_<n>_Rally`, from the params `start_building_<faction>` and `start_units_<faction>` the import writes (`packages/zero-hour/scripts/mode.rhai`).
- **`spawn_unit` tests a box alone for room.** A box spawned where a wall, a static body or a box the same call spawns lies is refused with `NoRoom`; a circle is never tested (`mode/src/mode_api.rs`, `NavigationColumn::room_for`).
- **A building frees its units only as its site completes.** A producer's `free` units and kept `spawns` leave as its site completes (`production/src/construction/mod.rs`); a building a script spawns whole frees none, where Zero Hour's `SpawnBehavior` spawns as its object is made, whatever made it.

## Other games

- **OpenRA's starting units.** A lobby option, `startingunits`, picks a class of start; each class names, by faction, a `BaseActor` spawned at the spawn point and `SupportActors` spawned in cells of the annulus from `InnerSupportRadius` to `OuterSupportRadius` round it, each cell drawn at random from those it may enter and reach, and a unit with no cell left is skipped ([`SpawnStartingUnits.cs`](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Common/Traits/World/SpawnStartingUnits.cs), [`MapStartingUnits.cs`](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Common/Traits/World/MapStartingUnits.cs)).
- **OpenRA's lobby starts a game of bots and a watcher.** `CheckAutoStart` starts a game once every human player and the host, who may spectate, are ready, the map's required slots are held, and any slot is held, a bot's among them; a dedicated server also needs two human players unless its `EnableSingleplayer` is set, which a server that is not dedicated always sets. A server that is not dedicated shuts down as its host leaves, and a dedicated one cleans up once every client left ([`LobbyCommands.cs`](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Common/ServerTraits/LobbyCommands.cs), [`Server.cs`](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Game/Server/Server.cs), [`Settings.cs`](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Game/Settings.cs)).
- **OpenRA's developer mode.** A lobby checkbox, "Debug Menu", off by default, gives each player cheats of fast build, cash, all tech, build anywhere and no fog, the cash 20,000 by default ([`DeveloperMode.cs`](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Common/Traits/Player/DeveloperMode.cs)).
- **StarCraft II's placement search and complete units.** `UnitTypePlacementFromPoint(type, player, point, range)` gives a point near `point`, within `range`, where a unit of `type` may stand, or null when the placement fails, and `UnitTypePlacementTestsFromPoint` names which tests it runs; `UnitCreate` makes a unit whole unless its style holds `c_unitCreateConstruct`, which starts it under construction ([`natives.galaxy`](https://github.com/SC2Mapster/SC2GameData/blob/master/mods/core.sc2mod/base.sc2data/TriggerLibs/natives.galaxy)).
- **Age of Empires II's placement and Empire Wars.** A random map script's `create_object` takes `find_closest`, which places an object at the nearest tile that its other rules allow ([Forgotten Empires: RMS features](https://www.forgottenempires.net/age-of-empires-ii-definitive-edition/rms-features)). Empire Wars starts every player in the Feudal Age with 27 villagers at work, economic buildings and a barracks ([Age of Empires: Empire Wars](https://ageofempires.com/games/aoeiide/empire-wars)).
- **Bot matches with a watcher.** Tempest Rising's patch of 29 April 2026 lets a custom game hold AI bots alone, which a player watches from a spectator slot ([patch notes](https://support.saber.games/hc/en/tempest-rising/articles/april-29-2026-patch-notes-24)); a player on the Age of Empires forum reports that a skirmish of AI alone still seats them as a player ([forum](https://forums.ageofempires.com/t/skirmish-is-bugged-cannot-spectate-a-game-with-only-ais/268055)).
