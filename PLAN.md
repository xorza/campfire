# Plan — current slice

The steps of the current slice ([Workflow](AGENTS.md#workflow)), in order, open items only: remove a step when it is done. Each step ends with the check chain passing for the crates it touches, and a stop for review. The slice ends when the user plays it in the client.

## Slice 1 — A Zero Hour map on screen

The user imports their install with `campfire-import`, starts `campfire-client --local` on Tournament Desert, and sees its terrain, its tiles, blends and cliffs, and its placed objects drawn with Zero Hour's models at their places and angles, from a camera that pans, zooms and turns as the original's does. Nothing moves, and no rule runs. The design is [Zero Hour](docs/design/12-zero-hour.md), the package rules of [Packages](docs/design/05-protocol-spec.md#packages) and [Game package](docs/design/03-game-scripting.md#game-package), and what the import reads is [Zero Hour research](docs/research/zero-hour.md). A step that changes a golden says why in its commit, with the number that moved.

1. **Z7. Models** (`campfire-import`, `package`; design 12): the object INI files as the game loads them, refused when their blocks do not close; each object's draw modules of the `W3DModelDraw` family and `W3DTreeDraw` and `W3DPropDraw`, with `ObjectReskin` and later definitions resolved; each one's default model and default look, the sub-objects its default state hides; W3D's chunks; each model the objects name once, an `HLOD` on its hierarchy, from its own file or another, or a mesh alone, into `client/models/<name>.glb`, its pivots as nodes, its sub-objects as named nodes on them, skins in their bind pose: positions, normals, the first stage's coordinates, vertex colors, triangles as one primitive for each texture, shader and vertex material; materials of diffuse, opacity, emissive, the texture by the game's lookup and its clamping, two-sided, opaque, an alpha test at 96/255 or a blend; a material file for any other shader; the glTF JSON through `common`'s `codec`, the binary container by hand; `client/units.toml` with each object's models and hidden nodes; the formats of `client/units.toml` and of a material file as types of `package`. Check: a fixture HLOD of two meshes on two pivots gives the nodes and vertices computed by hand, and an additive mesh's material file; a fixture INI gives the models and hidden nodes computed by hand, with a reskin and a muzzle flash; the install check converts every model the objects name but those no archive holds and the particle emitters, and reports those.
2. **Z8. The package asset source** (`client`, `package`; design 12): a Bevy `AssetSource` whose reader reads through `PackageFiles::read_file` on a blocking task; Bevy's `bevy_gltf`, `ktx2` and `png` features; each of a unit type's `models` from `client/units.toml`, drawn at its unit's place and angle with the nodes it names hidden, each primitive's material from its material file if one has its glTF material's name, and its `height` above the terrain's height there, as the original's interpolation of the heightmap gives it; a type with no model drawn as now. Check: a fixture package's model loads through the source, and one whose bytes differ from its row fails, logged with its path; Bevy's KTX2 loader reads the import's two fixture textures, a DDS's BC1 and a TGA's RGBA8, with their levels; the height at a point between four cells is the one computed by hand.
3. **Z9. Terrain** (`client`; design 12): the heightmap as a mesh of cells 10 units wide, each cell's two triangles split as the original flips them; the texture classes cut into tiles, packed in an atlas at load; each cell's tile, its blend tile with its alpha pattern, horizontal, vertical, either diagonal, inverted or long, its third blend, and its cliff UVs, in one material. Check: the vertices and the split of a fixture's 4 × 3 cells as computed by hand; the alpha of each pattern at its corners and its centre as computed by hand; Tournament Desert, through the install check, draws with no cell untextured.
4. **Z10. The camera** (`client`): the original's default pitch, height and field of view from its `GameData.ini`, as the importer writes them into the package's client data; edge and key scrolling, zoom between its limits, and turning about the point in view. Check: the camera's position and look from the defaults as computed by hand; zoom stops at each limit.
5. **Z11. The rules package and the install check** (`package`, `capabilities`, `campfire-import`, `packages/zero-hour`, new check `campfire-zero-hour-check`; D7): a mode's `script` as `{ package, path }`, a dependency's script, checked at load as its own are; `source/packages/zero-hour/`, which the imported package depends on, with the mode script of a map that only stands; the imported package as the mode, of one slot, with the fewest capabilities a map that only stands needs; the check in `source/checks/`, which imports the install `GENERALSZH_DATA` names, fails when it names none, prints the fingerprint, checks that Tournament Desert imports to 270 × 340 samples, 580 units of 63 types and 28 markers past its 176 road ends, loads it in a match and plays a tick. Check: a mode whose script is a dependency's loads and runs it, and one that names a dependency it lacks, or a path that dependency lacks, fails its load with what it named; the check passes on the Mac and on the Ubuntu host with the same fingerprint; the user runs the client on Tournament Desert and sees the slice's end.
