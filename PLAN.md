# Plan — next steps

The concrete steps of the current stages of the [roadmap](ROADMAP.md), in order, open items only: remove a step when it is done, and a section when it is empty. Each step ends with the check chain passing for the crates it touches, and a stop for review. A later stage's steps come here when it starts, after its design step ([Workflow](AGENTS.md#workflow)).

## Structure and names

The design is [Structure and names](docs/design/12-structure.md): one rule for each kind of value, one place for each error, one name for each meaning, and one copy of each piece of wiring. The renames, moves and splits come first, as pure refactors whose tests move with the code and pass unchanged; the shared parts follow, each with its tests. The net scenarios, the restore and checkpoint tests, and the LAN check pass at each step.

1. **R1. Names** (net, protocol, log, store, capabilities, runner, server, client, verifier, lan-check; [U8](docs/design/12-structure.md#decisions)): every rename of U8's table, each file and module with the type it holds; design docs that name the old names follow. Tests: `capabilities`' role names test, which lists `UnitOrder` alone as its exception.
2. **R2. Layout** (net, runner, verifier; [U7, U9](docs/design/12-structure.md#decisions)): `net`'s `sim_server/`, `local/` and `harness/`, and `client_dir` into `sim_client/`; `runner`'s `harness/`; `events/` in `runner` and `verifier`. Tests: none new, a pure move.
3. **R3. Files** (protocol, net, sim, capabilities, client, package, script, math, runner; [U9](docs/design/12-structure.md#decisions)): `SessionHeader`, `Applied`, `DurableHead`, `TickHashes` and `PlayerLink` each in a file of its own; the nine fat inline tests into `tests.rs`; the eleven free `pub(crate)` functions as methods; `Debug` on `Drawn` and `Variant`; one path form in each `lib.rs`; `capabilities`' layer list in its `lib.rs` as the layer test holds it. Tests: none new, a pure refactor.
4. **R4. Errors** (every crate with an error; [U5, U6](docs/design/12-structure.md#decisions)): `thiserror` as a workspace dependency of each; every error derives `Error`, its messages unchanged; each error in the `error.rs` of the module that makes it, `package`'s in `error/`. Tests: the existing ones, which read the messages, pass unchanged.
5. **R5. Values of 32 bytes** (common, protocol, sim, net, verifier; [U1](docs/design/12-structure.md#decisions)): the same derives on every one; `InputHash`, `SeedCommitment` and `ConnectChallenge` on `Bytes32`; `DelegationId` and `SeedContribution`; `TypeHash::hash` a `Bytes32`. Tests: the table of every type's text, parse and encoding.
6. **R6. The binaries' shared parts** (common, protocol, net, server, client, verifier, lan-check, design 10; [U2, U3](docs/design/12-structure.md#decisions)): `ExitStatus`, and one conversion of an `AppExit`; the OS's `fill` and `unix_now` in `net`, `getrandom` moved there from the client and the server; the random key in `protocol`; `SlotBotFile` and `OrderScript::read`; the server's `--server-bot`, in design 10 and the LAN check too; flags in any order; each binary's `ArgsError`. Tests: `ExitStatus`'s codes; `SlotBotFile`'s parse and refusals; each `ArgsError`'s cases; the server's flags in any order; the random key past an invalid secret.
7. **R7. App wiring** (net, server, client; [U4](docs/design/12-structure.md#decisions)): `SimServer` and `SimClient` add their plugins, the replication observer, the prediction manager and the client's entity; the server, `LocalServer`, the harness and the tests add only their own; one headless frame. Tests: none new; the net scenarios and the LAN check cover the wiring.
8. **R8. Test helpers** (protocol, store, net, server, runner, capabilities, package; [Shared test helpers](docs/design/12-structure.md#shared-test-helpers)): the key of one byte in `protocol`'s `internals`, for every test; `tempfile` as a dev-dependency of `store`, `net` and `server`, and `TempDir` in every test, `ScratchDir`, `Scratch` and the hand-made directories gone; `Aim`, the tick rate and the builders in `runner`'s `scripted.rs`; `PackageContent`'s list of keys. Tests: the list of keys names exactly the fields.
