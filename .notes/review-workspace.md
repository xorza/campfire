## Proposal

### Root causes

1. **A rider leaves every default query, and no reader of "every unit" was checked against it.** Interaction makes a rider `Disabled`, so grids, scans and collision skip it. But production's holdings, the victory's drain and the minimap also count "every unit" through plain queries. Each of them then disagrees with its own incremental path and with a restored world (`play-1`, `play-2`, `apps-1`, `play-14`).
2. **The holds of one modifier share one instance, but each hold goes through a script's application path.** An instance has one rank, while each hold asks for its own rank. A join or a rank-up runs the modifier's `reapply`. Two grant sources keep their own revisit rule outside the one pass (`combat-1`–`combat-4`). The `Hold` enum in `stats` lists the grant sources of the crates above it, and its `u8` is full (`combat-5`).
3. **Untrusted values are bounded by a downstream `expect`, a `debug_assert` or the caller, not where they are read.** The importer: a modifier name clash, a road width, a decoded WAV size, a slot count (`imp-1`–`imp-3`). The console's tick count and its non-UTF-8 lines (`ses-1`, `ses-4`). The server's input acks (`ses-2`). The packet bodies and the handshake tails (`nt-2`). Restored navigation state (`spatial-2`). `InputStream`'s bound and `RgbaImage`'s shape (`fnd-3`, `fnd-4`). A replicated message that maps to no tick (`ns-1`).
4. **An invariant is held by call order, not by its owner.** The route budget resets inside one system, so scans in other stages count against nothing (`spatial-1`). A held order releases its observers in query order (`play-4`). Replicon's completion stands for the history's completeness, while the write functions drop what Replicon counts (`ns-1`).
5. **The rules decide on text, and their reach is a list kept by hand.** The lookup rule misses a turbofish and every wrapper (`testing-1`). The ban rule accepts a commented-out ban (`testing-2`). The citation rule reads only some files (`testing-3`). Three more rules read formatted text (`testing-7`). Several decisions have no rule at all: no default method in the declaration traits, no `super::` imports, the game-name rule outside the capabilities, the name of a test-gated module, the layer of the network stack, and the doors of a proxied crate (`testing-8`–`testing-11`, `apps-4`, `nt-4`, `fnd-1`, `fnd-2`).
6. **Lists and facts are kept twice by hand.** The directive decoders (`cap-1`), the audit's observers and tags (`cap-2`), enum variant lists that `EnumAll`/`NamedEnum` derive (`apps-2`, `cap-4`), the unit types numbered twice (`core-2`), the replay-respawn list in two crates (`ns-3`), the confirmed-history seeding written twice (`ns-6`), production's model bones beside `Additions` (`imp-4`), the importer's mirrors of the modifier and area sections (`imp-5`), and rules copied between two movers or two callers (`spatial-5`, `spatial-6`, `spatial-8`, `play-7`, `play-11`, `nt-5`).
7. **Some passes do not visit only what changed.** A firing rider's retarget marks `Riders` changed (`play-5`). Ground containers keep the boarding state of fliers (`play-6`). A predicted spawn moves archetypes once for each part (`ns-2`). A model's hidden nodes are found by name at each shot (`apps-6`). The command panel rebuilds its layout each frame (`apps-8`). The idle scan prices weapons before its cheap filters (`play-10`). The Zero Hour bot scans the view some 110 times per think (`play-8`).
8. **The importer holds its outputs to the end of the write by default.** Only the models wait for a reason. The parsed meshes, the sounds and the terrain textures wait with them and add to the same peak (`imp-6`, `imp-7`).
9. **One test reserves every core for serial work, and the kill bound assumes a test runs alone** (`testing-4`, `testing-5`).

### Target design

- **Riders.** Every reader of "every unit a player owns" reads `Allow<Disabled>`, and the holdings observers mark a unit as it starts or stops riding. One riding test trains against a supply cap with a rider inside, both live and after a restore. The victory test kills a fallen player's rider.
- **Modifier holds.** A hold's grant is not an application. The instance keeps one rank that its holds agree on. A rank change renews the shares at the new rank and keeps the stacks. A hold that joins an instance only joins it. The type's passive and the shot streak are grant sources of the one pass through `UnitRun::hold_exactly`. Each module declares its own hold, and stats numbers the holds at install.
- **Boundaries.** Each value read from a game file, a tool, a peer or a snapshot is checked where it is read. The check is a checked type or an error case, never an `expect` or a `debug_assert`. A packet body is read as an exact type. `InputStream` stops at its bound. `RgbaImage` is built only by a checked constructor. A replicated message that names no tick unlinks the peer.
- **Owners hold their invariants.** The route budget resets as the tick begins, and every scan counts against it. Held orders release in stable-id order from a `DueIndex`. Navigation's state checks bound what its arithmetic reads.
- **Rules read tokens and parsed formats.** Every rule reads `syn` or the TOML that `codec` parses, never raw text. Each rule checks its samples in a test of its own. A rule's reach is the whole workspace, or an `Allowlist` that fails on a stale entry. New rules hold: no default method in a declaration trait, no `super::` outside a gated module, game names only in a game's module in every crate, a test-gated module named `samples` or `reach_in`, the network stack's layer, and only a proxy depends on the crate it proxies.
- **Declared once.** A module declares the directive it reads, and the catalog walk records its decoder. The audit pins every declaration kind in `declared.txt`. Enum lists come from `EnumAll`/`NamedEnum`. `UnitTypes` takes its numbering from `BookCx`. Prediction owns the one replay-respawn list. One seeding function in `net-replication` serves both pipelines. The importer writes the engine's own section types, which derive `Serialize`.
- **Change-driven passes.** `Riders` changes only when a rider comes, leaves or moves a fire point. Only fliers keep boarding state. A predicted entity gets all its histories in one insert. The dress resolves hidden nodes to entities once. The command panel rebuilds only on a change of its inputs.
- **The importer writes as it converts.** Sounds and terrain textures go to the package writer as they convert. A W3D file gives up its meshes once its render objects convert.
- **Test time.** The 3v3 scripted match reserves every core only for its parallel replay. The default profile kills a test at a bound that a full run on shared cores can keep.
