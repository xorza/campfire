# Review: the whole workspace

Eleven reviewers read the workspace slice by slice, on 2026-10-29, against AGENTS.md, the owner's guide and the design. The tests ran once: 2726 passed in 25.5 s, 12 of them over 1 s. Paths are relative to `source/crates/` unless they start with `source/`, `docs/` or `.notes/`. Each item is labelled by its slice and number (`ses-1`) so the proposal can name it.

## Proposal

### Root causes

1. **Untrusted input is bounded by its callers, not by the type read at the boundary.** The session log's decode checks signatures and structure but not the numbers its internals index by (`ses-1`, `ses-8`). The network's `Reader` exposes `bytes::Buf`'s panicking reads, and fragment counts are `u64` checked downstream (`nt-5`, `nt-7`). The handshake's crypto stream charges bytes, not entries (`nt-8`). The WAV reader multiplies unchecked (`imp-15`). Inside the sim, `Position` is a `DerefMut` over `Vec3` and `SinCos` has public fields, so their bounds are promises (`fnd-4`, `fnd-10`).
2. **Invariants live in doc comments and discipline instead of types, lints and `rules`.** The schedule, task-pool, base64 and store bans list entry points by hand and miss the other doors (`fnd-1`–`fnd-3`). `DurableFile::write` relies on one writer per name (`fnd-5`). A late schedule must remember `run_on_one_thread` (`fnd-14`). Package reproducibility relies on nobody calling libm or glam's `Quat` (`imp-1`). The 1 s exemption is a name filter any module can take (`testing-1`, `testing-3`). The layer test the design cites does not exist, the gate reader knows two spellings, two rules decide on raw text, and no rule keeps a game's names in its own module (`testing-4`–`testing-8`).
3. **Lists are kept by hand where the Direction asks for one declaration and one walk.** Eight projection consumers of `Declarations` each re-walk the release for one list (`cap-3`, `cap-4`). The top crate hand-lists name kinds, directive decoders, the map's pathing and an action loader that misses three books (`cap-1`, `cap-2`, `cap-6`, `cap-7`). The importer gathers each type's sections through 19 stage maps (`imp-3`). Five grant sources each hand-roll their revisit rule and their wanted/held diff (`gameplay-3`, `-4`, `-8`). Three net registries are copies (`ns-3`). The Zero Hour check states each measure three times (`testing-12`).
4. **Code sits in the wrong layer.** `net` is session glue filed as the network group's top crate, which is the whole answer to "why network depends on script" (`nt-1`). The match's names, tags, teams, filters and data tables live in the Rhai crate, and the script runtime is installed by `Units` (`core-1`, `core-2`). Prediction's `Diffable` and three ECS utilities live in `net-replication` (`ns-4`, `ns-5`). Thread utilities live in `store` (`fnd-6`). Airfields writes production's and combat's parts (`spatial-1`, `-2`). The generic walk holds Zero Hour's driver and pace (`spatial-4`, `-5`). The importer's format readers hold import policy and engine limits (`imp-7`, `imp-8`). Contract parts keep their old modules' state names, and their state impls sit in `values` (`core-6`, `core-7`).
5. **Passes do not visit only what changed.** The minimap, the fog, particles and tracks rebuild and re-upload their whole asset each frame or change. `face_camera` trusts `Changed<Window>`, which every cursor move sets. Bones and flashes are found by name at each shot (`apps-3`–`apps-7`). `Riders` is marked changed every boarding tick (`gameplay-2`). Every rollback starts a 2 s correction on every corrected entity, error or not (`ns-2`).
6. **The session journal does not hold its own shape, and the log keeps the whole past although only its latest checkpoint is ever loaded.** So each publication reads the journal twice, a report in flight with a checkpoint has no log, and a restore re-checks every signature of the session (`ses-2`–`ses-4`, `ses-9`).
7. **Integrated test fixtures are made test by test.** Net-harness files copy fixtures and verify routines, cases run serially in one body, and the proving match plays whole in three tests (`testing-1`, `-2`, `-9`, `-10`, `cap-8`, `cap-9`).

### Target design

- **Boundaries.** Each value read from a peer, a log or a game file is a checked type whose constructor refuses what the protocol or the format forbids: one gate in `SessionLog::within` and `start_at_checkpoint`, `u16` fragment newtypes, a `Reader` with checked reads only, an entry cost in the crypto stream, checked WAV arithmetic. Inside the sim, `Position` is a checked newtype with `Deref` only, and `SinCos` has private fields.
- **Enforced invariants.** The bans name the door types (`TaskPoolBuilder`, `base64::engine::GeneralPurpose`, the `App`/`SubApp` mirrors, the `std::os` link calls). `rules` gains a layer rule over the crate groups, a full gate reader, a game-name rule, a one-`scripted_match`-per-mode rule and a `NAME`-prefix rule, and every rule reads `code()` or tokens. The importer's clippy config bans platform trig and `Quat`. `DurableFile::write` takes a unique temporary.
- **Declared once.** One `ReleaseCatalog` consumer records every value-shaped declaration, and `Release`'s lists filter it. Modules declare their name sets, directive types and derived caches. The importer's stages are types that write their files as they convert and add their sections to one `TypeSections` accumulator. A `UnitRun::hold_exactly` diff serves every grant source. One sealed rule-table kit serves the three net registries.
- **Layers.**
  - `base` < `sim` < `capabilities/core` < `capabilities` < `session` < `network` < `apps`, `test`, `checks`.
  - A Rhai-free `names` crate sits below `script`. A `Scripts` module installs the runtime before `Units`.
  - `net` moves to `session/`, and `net-stack` tops the network group. `client-files` moves out of `session/`.
  - `Exchange`, `LatestWriter` and one `BufferedWorker<Policy>` live in `threads`.
  - Production owns place, door and home writes behind a units-level contract that airfields calls. `MovementModel` is the movement interface, and its Zero Hour driver lives in `navigation::zero_hour`.
- **Change-driven passes.**
  - The dress resolves every node a look names into entities.
  - The minimap and fog repaint only on a tick, a cell or a camera change, and write in place.
  - Particle meshes are filled in place and live in the render world only.
  - The window gate reads resize and scale events.
  - Corrections start only on a real error.
  - `Riders` splits its progress from its configuration.
- **Session journal.** `Journal` keeps a `JournalShape` as it appends, including its last publishable byte. The log's base is its latest checkpoint, `load` takes no segment, and older segments keep only their number and tick.
- **Fixtures.** Each mode has one `scripted_match` that checkpoints and replays its segments in parallel. `InProcessMatch` and `Moba3v3` gain presets. Capability fixtures are spawn presets, with one `Match::step_orders`.

### 1. The session log refuses what its internals cannot hold

Files: `session/protocol/src/session_log/{mod.rs, log_entries.rs, paged_vec.rs, checked_carry.rs, segments.rs, server_seed.rs, server_seeds/mod.rs, file.rs, log_replay.rs}`, `session/protocol/src/session_terms.rs`, `session/protocol/tests/segments.rs`.

- [ ] **ses-1** (`session_log/mod.rs:1273-1326`, `:1424`; `session_terms.rs:115`; `paged_vec.rs:34-46`; `checked_carry.rs:70-75`; `segments.rs:89-91`; `server_seeds/mod.rs:16-23`): a signed log of a few hundred bytes crashes the verifier or the client's report reader, uses all its memory, or makes it run for minutes. Each refusal is its own `HeaderError`/`CheckpointError` variant. `CheckedCarry` adds checked. `ServerSeeds` of a file starting at segment k holds k..=last. Test: a table beside the carry-flaw table in `tests/segments.rs`, one row per case, each refused with its own error.
- [ ] **ses-8** (`session_log/mod.rs:1217-1266`, `:1391-1403`; `log_replay.rs:28-50`): `load(k)` for k below the base left by `forget_before` makes a later restore read dropped pages and panic. Today only `load_latest` calls it, but the public API and the journal's LOADED replay accept any segment. → `load` takes no segment and loads the latest, or refuses a segment before the base with an error.

### 2. The server bounds its live sessions, and its sockets mean one thing on every OS

Files: `network/net-udp/src/{admission/mod.rs, secure_establishment/server_side.rs, crypto_stream.rs}`, `network/net-socket/src/udp_port.rs`, `base/platform`, `network/net-payload/src/packet_session_queues.rs`, `network/net-link`, `docs/design/11-net-stack/udp.md`.

- [ ] **nt-2** (`admission/mod.rs:155-181`; `server_side.rs:43`, `:360-363`; `net/src/sim_server/offering.rs:44`): only pending handshakes have a server-wide bound. A validated session leaves `pending`, and only its /64 bounds it. An attacker on many /48s passes the Retry, completes TLS, and holds each link for the 10 s answer window. So live links grow without bound. This is the open part of the TODO "anti-dos connection challenge", because the Retry challenge already exists. → A server-wide cap on live sessions plus pending handshakes, taken from the session's player slots and spectators with a margin in `AdmissionSetup`. It refuses after the Retry and before TLS, as quinn's `max_incoming` does. Test: with a cap of N, the (N+1)th validated Initial from a new /48 is refused and starts no TLS, and the next is admitted after one session ends.
- [ ] **nt-3** (`net-socket/src/udp_port.rs:47-48`): `IPV6_V6ONLY` is never set. It defaults to 0 on Linux and 1 on Windows, so a server on `[::]` answers IPv4 clients on Linux only. Decided 2026-10-29: dual-stack, as RFC 3493 §5.3, Go's `net.Listen` and GameNetworkingSockets do. Refused: IPv6-only, under which a host on `[::]` silently loses its IPv4 players. → `UdpPort::bind` sets `IPV6_V6ONLY=0` on an IPv6 socket through the platform crate's `socket2`. udp.md records the decision, and port-map.md's "IPv4 alone" lets a dual-stack `[::]` bind map its IPv4 port. Test: a socket on `[::]:0` receives from `127.0.0.1` on every OS lane, if dual-stack is chosen.
- [ ] **nt-8** (`crypto_stream.rs:7-38`): `held` counts only bytes. So 65,536 one-byte pieces hold about 4 MiB per stream, against transport.md's "each entry costs its slot". → Charge each piece its length plus a fixed entry cost, as `PARTIAL_COST` does. Test: the count of held pieces is `MAX_AHEAD / (len + E)`, computed in the test.
- [ ] **nt-9** (`packet_session_queues.rs:157-164`): `clear` keeps `overhead` and `max_payload`, against connection.md's "An unlinked link holds nothing of its last connection". `Channels::flush`'s guard reads the stale value. → `clear` resets every field to `Default`. Extend `an_unlinked_link_holds_nothing_of_its_last_connection` with `max_payload() == 0`.
