# Foundational issues

The open problems whose cause is in the architecture or in a format the project chose, not in one piece of code: each shows as several items of the [issue log](ISSUES.md), or limits every system built after it. Each entry names its cause, what it limits, and the issue-log items it holds. The rules are in [AGENTS.md](../AGENTS.md#issue-log).

- **Replication has no audience for each state type** (Net, Stats). A capability's network data goes to all that see a unit, its team or its owner by the design, but the code has only each unit's rooms, one owner-only component, and no path for state outside an entity. Every capability with network data meets it, a client receives what its player must not know, and prediction lacks what it reads. Items: Net, "Replication has no audience for each state type"; Net, "No production state replicates"; Net, "Every replicated component of a unit goes to every client"; Stats, "A held modifier whose numbers come from its source".
- **The script view copies the whole match** (Core). Each script batch reads every unit again, though few change between two batches of a tick: 14.2 % of a 3v3 match's time, a cost that grows with the units times the batches, which the Zero Hour import multiplies. Items: Core, "The script view copies the whole match".
- **The import's materials are glTF's** (Zero Hour). glTF's material model holds no W3D pass past the first, no ambient color and no fallback texture, so the presentation loses each, and each later fidelity gap of a W3D material meets the same limit. Items: Zero Hour, "The import writes W3D's materials into glTF's material model"; Zero Hour, "A texture no archive holds"; Zero Hour, "The import ignores a vertex material's ambient color"; Zero Hour, "The import draws a mesh's first material pass".
- **The import has no object that only the client shows** (Zero Hour). Every object a map places becomes a unit of the sim, where the game spawns props, optimized trees and fluff on the client alone and some objects not at all, so the sim, its log and its state hash hold objects the original never simulates, and the parity oracle meets them. Items: Zero Hour, "The import makes a unit of every object a map places".
- **The transport** (Net). WebTransport's one gain over QUIC alone is a browser's reach, which the project dropped; the handshake binds to the TLS certificate's hash, so the choice sets the protocol of design 05. Items: Net, "The transport is WebTransport".
